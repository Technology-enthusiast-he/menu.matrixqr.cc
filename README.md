# 🍽️ MatrixQR - Digital Menu QR Code Generator

[![Website Status](https://img.shields.io/website?url=https%3A%2F%2Fmenu.matrixqr.cc%2F)](https://menu.matrixqr.cc/)
[![License: MIT](https://img.shields.io/badge/License-MIT-blue.svg)](LICENSE)

A lightweight, privacy-focused, and client-side **Digital Menu QR Code Generator** designed for restaurants, cafes, bars, and food trucks. Easily convert menu links, digital files, and ordering platforms into scannable QR codes for touchless dining experiences.

🔗 **Live Demo**: [https://menu.matrixqr.cc/](https://menu.matrixqr.cc/)  
🌐 **Main Site**: [https://www.matrixqr.cc/](https://www.matrixqr.cc/)

---

## ✨ Features

- ⚡ **100% Client-Side Processing**: Fast generation with zero latency.
- 🔒 **Privacy-First**: No data tracking or server-side logging of menu URLs or content.
- 📱 **Mobile & Touch Optimized**: Clean, responsive layout for desktop, tablet, and smartphone browsers.
- 🎨 **Custom Styling**: Tailored for contactless dining setups (table stickers, counter stands, window posters).
- 📥 **High-Quality Export**: Instant PNG export with no watermarks.
